# Deviations from the pre-registered design

| # | Deviation | When / why | Effect on conclusions |
|---|---|---|---|
| 1 | Source-calibrated baselines use the union of out-of-fold source-training residuals and source-calibration residuals. | Decided **before any result was computed** (fairness: corn has only 10 calibration samples); added to the pre-registration text before the first run. | Favours the baselines (larger calibration pool). |
| 2 | 1D-CNN (mango, E5): σ(x) and the source residual pool use source-calibration residuals instead of 10-fold OOF residuals; the CNN is trained once with early stopping on a 10% split of source training. | Implementation stage, for compute reasons (no 10-fold CNN retraining). Decided before any CNN result. | None on validity (σ is still fixed before target data are seen). |
| 3 | The PDS solver uses an eigen-decomposition of the window Gram matrices instead of an SVD pseudo-inverse. | Implementation stage, for speed. Numerically identical (max coefficient difference 5e-12, tested). | None. |
| 4 | A CNN prediction cache keyed by array memory address returned stale predictions during a smoke test. It was removed before any reported CNN run. | Bug found in the 3-repetition smoke test. | None on reported results (bug fixed before the full run). |
| 5 | The full grid could not finish within one 2-hour background job. Execution was made resumable by repetition chunks (`--rep-start/--rep-end`, files `<exp>@rAAAA-BBBB.csv.gz`, merged at analysis with a duplicate check). Seeds depend only on the repetition index, so the chunked results are identical in design to a single run. | During execution (infrastructure). | None. |
| 6 | Raw result files were compacted for archiving: 6 significant digits (maximum relative change 5e-6, infinities preserved); per-sample error-analysis files keep only the *m* shown in Fig. 8 (corn 15, tablets 20, mango 20). All reported statistics were computed from the compacted files. | After the runs (GitHub 100 MB file limit). | None (verified). |
| 7 | **E8 added (external validation):** mango instrument shift using paired spectra from the providers' extended file (Mendeley record v6, `MangoDMC_NIR_Data_v4.csv`). Source = instrument 15006 (fruit not measured on the target instrument), targets = 15016, 15014, 15029 (largest numbers of paired fruit), PDS primary and SBC secondary, m ∈ {10, 20, 30, 50}, 200 repetitions, all methods, α ∈ {0.05, 0.1, 0.2}; outlier-flagged spectra (outlier_flag_1 ≠ 0) excluded; replicates averaged per fruit and instrument. | Added in response to review round 5 (external validity). Design fixed before any E8 result was computed. | Additional evidence; does not alter E1–E7. |
| 8 | **Citation correction:** the mango file used in E1–E7 is from record version 1 (doi:10.17632/46htwnp833.1); E8 uses version 6 (doi:10.17632/46htwnp833.6). | Found during the review-5 data audit. | None on results. |
| 9 | **Bug fix (review round 4, code audit):** in the LV-sensitivity runs (E7_lv) the ±2 LV offset had been applied after source-model selection. Predictions used A±2, but σ(x), the out-of-fold residual pool (SCP-S/WCP-S/Transport) and the SEC (ASTM-PI) were still computed at the originally selected A. The offset is now applied inside `fit_source_model` before these quantities are computed. E7_lv was re-run; the superseded files are archived in `results/raw/superseded_E7_lv/` and are not used. | Found in review round 4. | Affects only the LV-sensitivity analysis (Table S3). |
| 10 | **E9 added (competitor analysis, review round 8):** heteroscedastic Gaussian interval Gauss-LOO-N = μ ± t(m−1)·RMS(Rᵢ)·σ(x), compared with TJ+N and Gauss-LOO on all primary pipelines (corn PDS, tablets PDS, mango SBC) and on E8 (PDS, SBC), α ∈ {0.05, 0.10, 0.20}, 200 repetitions. Specified before any E9 result. | Review round 8 (competing-researcher critique). | Additional comparison. |
| 11 | **E4b added (review round 10):** sub-channel wavelength drift (±0.25 channel, linear interpolation) of the test spectra after standardisation; corn (4 properties, m5→mp5, m = 15, PDS), tablets (assay, m = 20, PDS), mango (m = 20, SBC); 200 repetitions; key methods. The `_shift` function was generalised to fractional shifts; integer shifts give identical results to the previous implementation. | Review round 10 ("±1 channel is unrealistically large"). Specified before any E4b result. | Additional robustness evidence. |
